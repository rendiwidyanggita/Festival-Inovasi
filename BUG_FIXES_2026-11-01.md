# Bug Fixes & UI Improvements - 2026-11-01

## 🐛 Bug yang Diperbaiki

### 1. Sidebar Tooltip Positioning Bug (Admin & Jury Dashboard)
**Masalah**: Tooltip pada sidebar collapsed muncul tidak pada tempatnya karena menggunakan `fixed left-20` yang tidak memperhitungkan posisi relatif parent element.

**Penyebab**: Penggunaan `position: fixed` dengan koordinat statis (`left-20`) menyebabkan tooltip selalu muncul 5rem dari kiri viewport, bukan relatif terhadap item sidebar.

**Solusi**:
- Mengubah positioning tooltip dari `fixed left-20` ke `absolute left-full ml-2`
- Menambahkan `top-1/2 -translate-y-1/2` untuk centering vertikal
- Menggunakan `opacity-0` default dengan transisi smooth ke `opacity: 1` saat hover
- Total 13 tooltip diperbaiki (10 menu admin + 2 menu juri + 1 conditional)

**File yang diubah**:
- `resources/views/components/layouts/app.blade.php`

**Verifikasi**: Tooltip sekarang muncul tepat di sebelah kanan ikon menu saat sidebar dalam keadaan collapsed.

## 🎨 UI Improvements

### 2. Homepage Conversion: Dark Mode → Light Mode
**Kebutuhan**: Homepage perlu menggunakan light mode yang clean, simple, dan professional.

**Perubahan**:
- **Background**: `bg-slate-950` → `bg-white`
- **Text**: `text-slate-100` → `text-slate-900`
- **Header**: `bg-slate-950/80` → `bg-white/90` dengan `border-slate-200`
- **Hero Section**: Gradien gelap → `bg-gradient-to-b from-slate-50 to-white`
- **Cards & Containers**: 
  - Border: `border-slate-800` → `border-slate-200` atau `border-2 border-slate-200`
  - Background: `bg-slate-900` → `bg-white`
  - Hover states: `hover:border-blue-300 hover:shadow-lg`
- **Buttons**: 
  - Primary: `bg-blue-600` dengan shadow halus
  - Secondary: `bg-white border-2 border-slate-200`
  - Active state: `active:scale-[0.96]` untuk tactile feedback
- **Typography**: 
  - Headings: `text-slate-900` dengan `font-extrabold`
  - Body: `text-slate-600` 
  - Muted: `text-slate-500`
- **Accent Colors**: 
  - Blue: `text-blue-600`, `bg-blue-50`
  - Success: `text-emerald-600`, `bg-emerald-50`
  - Warning: `text-amber-700`, `bg-amber-50`

**File yang diubah**:
- `resources/views/public/index.blade.php`
- `resources/views/public/festival.blade.php`
- `resources/views/public/category.blade.php`

**Design Principles Applied**:
- ✅ Clean, minimal white background
- ✅ Professional blue accent colors
- ✅ Subtle borders and shadows
- ✅ High contrast text for readability
- ✅ Smooth transitions and hover states
- ✅ Accessible color combinations (WCAG AA compliant)
